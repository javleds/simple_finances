# Decisiones arquitectonicas

Este directorio queda reservado para decisiones futuras que cambien contratos, limites de modulos, persistencia, integraciones, seguridad o comportamiento operativo.

No se crearon ADRs retroactivos durante el bootstrap porque el repositorio ya tiene documentacion de dominio existente y no conviene convertir inferencias historicas en decisiones formales.

Cuando se agregue una decision, incluir:

- fecha;
- contexto;
- decision;
- alternativas consideradas;
- consecuencias;
- rutas afectadas.
